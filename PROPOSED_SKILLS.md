# Proposed Skills

A running list of skills we'd like to add to this repo. Add a proposal below using the template, and move it to **Accepted** or **Rejected** once a decision is made.

## How to propose a skill

Copy the template, fill it in, and add it under **Proposals**.

```markdown
### <skill-name>

- **Status:** Proposed
- **Proposed by:** <name or GitHub handle>
- **Summary:** One or two sentences on what the skill does.
- **Use case:** When should Claude use it? What problem does it solve?
- **Example triggers:** Phrases or tasks that should activate it.
- **Dependencies:** Tools, libraries, or MCP servers required (if any).
- **Notes:** Open questions, links, prior art.
```
